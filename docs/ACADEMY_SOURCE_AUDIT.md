## Решение для этого PR

Создан **изолированный учебный модуль**, который можно проверить без доступа к production и перенести в актуальное приложение. `src/App.tsx`, `src/main.tsx`, текущие CSS и `index.html` не изменены. Новая отдельная точка входа: `academy-module.html`. Vite собирает обе страницы; существующая главная сохранена. Не добавлены аккаунты, секреты, интеграции и новый backend. Публичный деплой и слияние не выполнялись.

PR следует держать draft до установления актуального источника. Не разворачивать этот репозиторий поверх рабочей академии целиком.

## Как установить связь окончательно

В локальном проекте Академии прочитать `git remote -v`, `git status -sb`, `git log -1`, package manifests и конфигурацию deployment. На сервере проверить read-only конфигурацию Nginx для academy, document root, используемый сервис, release metadata и manifests. Не выводить .env и секреты. Сопоставить сборку и commit с опубликованными asset-файлами. После этого перенести модуль в реальную feature-ветку.
